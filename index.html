Work

Oracle

I'm a software engineer at Oracle, working on the Autonomous Database Serverless (ADB-S) platform. As a Senior Data Systems Engineer, I develop database infrastructure for backup, recovery, and cloning functionality for pluggable databases. I work in C and PL/SQL.

Much of my work focuses on making database functionality work reliably across regions, including implementing systems for persisting database metadata in cloud object storage and exposing database information through cross-tenancy APIs. I collaborate closely with engineers and technical leaders to deliver new features, and own several areas of database clone functionality.
